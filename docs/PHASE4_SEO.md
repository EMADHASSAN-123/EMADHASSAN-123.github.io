## 2. ما تم تنفيذه ولماذا

| البند | ما تم | السبب |
|-------|-------|-------|
| **الفهرسة** | إزالة `noindex` من الصفحات الست الحقيقية؛ إبقاؤه على 404 فقط | كان مقصوداً قبل اكتمال المحتوى؛ بدونه لا يظهر الموقع في البحث |
| **عنوان الموقع** | `site` = `https://emadhassan-123.github.io` افتراضياً (يمكن تجاوزه بـ `PUBLIC_SITE_URL`) | أساس كل العناوين المطلقة (canonical، OG، sitemap) |
| **الشرطة الأخيرة** | `trailingSlash: 'always'` + كل الروابط الداخلية `/path/` | GitHub Pages يقدّم الصفحات على `/path/`؛ التطابق يمنع تحويلات 301 لا داعي لها ويوحّد العنوان الذي يفهرسه Google |
| **Canonical** | `<link rel="canonical">` مطلق لكل صفحة قابلة للفهرسة | يحدد العنوان الرسمي ويمنع الازدواج (مثلاً `/path` مقابل `/path/` أو `?utm=`) |
| **خريطة الموقع** | `@astrojs/sitemap` يولّد `sitemap-index.xml` بست صفحات، مع استبعاد 404 صراحة | يعرّف Google بكل الصفحات ويسرّع اكتشافها |
| **robots.txt** | `src/pages/robots.txt.ts`: السماح للجميع + رابط خريطة الموقع | المعيار الذي تقرؤه محركات البحث أولاً؛ يُولَّد من نفس `site` فلا يختلف العنوان |
| **بطاقات المشاركة** | `og:type/title/description/url/image/locale` + `twitter:card` | شكل الرابط عند مشاركته في LinkedIn وWhatsApp وFacebook وX |
| **صورة المشاركة** | `public/og-image.png` (1200×630): الاسم باللغتين، المسمى، العنوان، والصورة في إطار "بطاقة المختبر" | المقاس القياسي لـ Open Graph؛ هوية بصرية مطابقة للـ Hero |
| **البيانات المنظمة** | الرئيسية: `Person` + `WebSite`. صفحات المشاريع: `CreativeWork` + `BreadcrumbList` | تخبر Google صراحة بهوية صاحب الموقع وعلاقته بالمشاريع؛ تساعد على عرض الاسم والمسار بشكل صحيح |
| **الأيقونات** | `favicon.svg` + `favicon-48.png` (حجم يقبله Google) + `apple-touch-icon.png` | تظهر في تبويب المتصفح ونتائج البحث على الجوال |
| **لون الواجهة** | `theme-color` للوضعين | لون شريط المتصفح على الجوال يطابق الموقع |

## 4. قيد معروف: اللغتان على رابط واحد

القرار المعتمد (`PHASE2_IA` § 4.1): رابط واحد لكل صفحة باللغتين، والتبديل بلا إعادة تحميل.

- **العربية:** هي اللغة الافتراضية في HTML (`lang="ar"`)، فستكون أساس الفهرسة.
- **الإنجليزية:** النص موجود في الصفحة لكنه مخفي (`display:none`)، فيُرجَّح أن يأخذ وزناً أقل في نتائج البحث الإنجليزية.
- **`hreflang` لا ينطبق** لعدم وجود عناوين منفصلة لكل لغة.
- **البديل إن أصبح البحث الإنجليزي أولوية:** عناوين منفصلة (`/en/...`). هذا **تغيير لقرار معتمد** يتطلب اعتماد صاحب المشروع.
