## 1. ترجمة المفهوم المحوري (Concept Translation)

### 1.1 الاستعارة الحاكمة

**Interactive Engineering Lab** — نموذج تنظيمي للموقع بأكمله، لا موضوع بصري فحسب: `[معتمد]`
- الموقع "مختبر رقمي" يدخله الزائر ليرى أدوات مهندس يعمل، لا معرضاً سلبياً للصور.
- كل قسم محطة في المختبر: محطة الهوية، محطة المنهجية، محطات المشاريع، محطة التواصل.
- كل مشروع "تجربة هندسية" موثقة: المشكلة، التصميم، التنفيذ، النتيجة.
- الحركة والتفاعل تخدم استكشاف النظام، لا الإبهار.

### 1.2 المبدأ الإبداعي الذي يميّز هذا الموقع

> **الوضوح قبل التأثير. البنية قبل الزخرفة. الدليل قبل الادعاء.** `[معتمد]`

### 1.3 القوس السردي (Narrative Arc) للزائر

رحلة من أربع لحظات، كل لحظة قائمة بذاتها ويمكن القفز إليها مباشرة: `[معتمد]`

1. **التعريف** — من أنا، وما الذي أعمل عليه؟
2. **المنهجية** — كيف أفكر في المشكلات؟
3. **الدليل** — ماذا فعلت فعلياً؟
4. **الدعوة** — كيف نعمل معاً؟

## 3. رحلات المستخدمين (User Journeys)

### 3.1 الفئات الأربع — مهام أساسية في زيارة واحدة

| الفئة | هدف الزيارة الرئيسي | أول 3 أقسام يحتاجها | إجراء التحويل |
|-------|----------------------|------------------------|-----------------|
| **صاحب عمل / Startup** | هل يمكن لعماد حل مشكلتي التقنية؟ | Hero → التخصصات → المشاريع (المشروع 3 مثال تطبيقي) | زر "ابدأ مشروعاً" → Contact |
| **مسؤول توظيف / HR** | هل يناسب دوراً تقنياً عندنا؟ | Hero → About/الخلفية → المشاريع → الشهادات → CV | تحميل CV + LinkedIn |
| **عميل Freelance** | هل يفهم ما أريد وينفذه؟ | Hero → المشاريع (3 أمثلة منفذة) → Contact | WhatsApp مباشر أو Contact Form |
| **مدير مشاريع / قائد فريق** | هل يمتلك قدرة تحليلية ومنهجية؟ | Hero → المنهجية → دراسة حالة (المشروع 1) → About | LinkedIn + قراءة دراسة الحالة |

### 3.2 حوصلة قرار IA من الرحلات

- **Hero إلزامية كـ Entry Point لكل الفئات** — المسار من Hero إلى أي قسم لا يتجاوز نقرتين.
- **المشاريع هي المحطة المشتركة للفئات الأربع** — تستحق أعلى استثمار في العرض.
- **المنهجية حاسمة لفئتين من أربع** — تستحق قسماً خاصاً.
- **الشهادات حاسمة لفئة واحدة فقط (HR)** — قسم مستقل لكن مختصر.
- **تعدد قنوات التواصل ضرورة** — لأن الفئات تفضل قنوات مختلفة.

### 5.2 محطة Hero — تفصيل `[معتمد]`

**العناصر الإلزامية:**
- الاسم بالعربية + الإنجليزية (hierarchy واضح).
- المسمى المهني: `Software & Applied AI Engineer`.
- عبارة موقف واحدة: "أصمِّم أنظمة وأبني حلولاً تجمع البرمجيات، الذكاء الاصطناعي، والبنية التحتية." (نص قابل للتنقيح في مرحلة التنفيذ).
- CTA أساسي: "استكشف المشاريع" → `#projects`.
- CTA ثانوي: "تحميل السيرة الذاتية" أو "تواصل".
- زر تبديل اللغة + زر تبديل Theme في الـ Nav الثابت.
- **Hero Visual (قرار محسوم):** خلفية معمارية هندسية خفيفة (شبكة نقاط / خطوط تدفق) + صورة شخصية بإطار "بطاقة هوية مختبر" مستطيل عمودي مع حدود هندسية. لا دائرة ضخمة، لا صورة ملء الشاشة.

**العناصر الممنوعة:**
- أي شعار تسويقي عام.
- أي متحرك يأخذ انتباه الزائر عن القراءة.
- Parallax على الصورة.

### 5.3 محطة Methodology — تفصيل `[معتمد]`

**الفكرة البصرية المعتمدة:** عرض الخطوات الثمانية كـ **خط أنابيب هندسي (Pipeline) أفقي** على Desktop، 8 عقد مرتبطة بخطوط. على Mobile: مكدَّس عمودياً.

كل عقدة تعرض:
- رقم الخطوة.
- اسمها.
- وصف من سطر واحد.

**نبرة النص:** فعلية، محايدة ("أحلل المتطلبات"، "أصمم المعمارية")، لا شعاراتية.

### 5.4 محطة Expertise — تفصيل `[معتمد]`

**التنظيم الإلزامي:** ثلاث مجموعات بصرية منفصلة وواضحة التمييز:

1. **تطبيقي موثَّق** (Applied) — مع ربط كل مهارة بالمشروع الذي يُثبتها.
2. **أكاديمي / قيد الإثبات** — قد يُحدَّث بعد استلام روابط GitHub.
3. **قيد التعلم والتطوير** (Learning).

**ممنوع:** نسب مئوية، شريط تقدم، نجوم تقييم.

**مسموح:** أيقونة بجانب كل مجموعة تقنية، وعدد المشاريع المرتبطة بكل تقنية في المجموعة الأولى.

### 5.5 محطة Projects — تفصيل `[معتمد]`

**ترتيب العرض (محسوم):** `1 → 3 → 2 → 4` (بترتيب القيمة المهنية).

1. المشروع 1 (Fuel Quality — أعلى تعقيد تقني وتكامل متعدد الطبقات).
2. المشروع 3 (Al Shifa Website — جهة حقيقية + موقع منشور).
3. المشروع 2 (Content Management — نموذج تطبيقي للمهارات).
4. المشروع 4 (Al Shifa MIS — يظهر مع شارة "قيد التصميم" واضحة).

**محتوى كل بطاقة في Preview:**
- شريط تصنيف أعلى (منفذ / منشور / نموذج تجريبي / قيد التصميم) بلون مختلف.
- اسم المشروع (عربي + إنجليزي مختصر).
- وصف من سطرين كحد أقصى.
- Chips صغيرة بأهم 4-5 تقنيات.
- زر "دراسة الحالة" → الصفحة التفصيلية.

**ممنوع:** صورة موك-أب ضخمة بلا صلة بالمحتوى الفعلي. البديل: عنصر بصري معماري مبسّط للمشروع.

### 5.6 محطة Certifications — تفصيل `[معتمد]`

**العرض:** صف أفقي قابل للتمرير على Mobile، شبكة 2×2 على Desktop.

**البطاقة:**
- أيقونة الجهة المانحة أو الحرف الأول من اسمها.
- اسم الشهادة الكامل.
- الجهة + التاريخ.
- شارة تمييز: "بمرتبة التميّز" للـ GMAI، "100%" لـ Introduction to AI.
- زر "عرض الشهادة" → PDF في تبويب جديد.

**التمييز البصري:** الفئة الأولى (GMAI + Introduction to AI) بحاشية أبرز؛ الفئة الثانية بشكل أبسط.

### 5.7 محطة Contact — تفصيل `[معتمد]`

**البنية:** عمودان على Desktop، مكدَّسان على Mobile.

- **العمود الأيمن (في RTL):** قنوات مباشرة — WhatsApp، LinkedIn، Facebook، Email — كأزرار كبيرة قابلة للنقر.
- **العمود الأيسر:** نموذج التواصل.

**وراء الكواليس:** Supabase Edge Function + جدول آمن (RLS) + Honeypot ضد Spam.

```
├─────────────────────────────────────────┤
│ 5. دوري ومساهمتي الفعلية                │
├─────────────────────────────────────────┤

└─────────────────────────────────────────┘
```

### 6.2 المخطط المعماري التفاعلي — نمط التنفيذ المعتمد

- **SVG مرسوم يدوياً لكل مشروع** (ليس Mermaid عام).
- **قابل للنقر:** كل عقدة (Node) عند النقر تُظهر Tooltip أو Panel جانبي يشرح دورها.
- **متسلسل القراءة:** تظهر العقد تدريجياً خلال ثانية إلى ثانية ونصف — يساعد على قراءة التدفق.
- **يحترم `prefers-reduced-motion`:** عندها يظهر كاملاً فوراً بلا تحريك.
- **متجاوب:** على Mobile يتحول إلى نسخة مبسطة عمودية، أو نسخة ثابتة قابلة للتكبير بالنقر.

**مثال محور — المشروع 1:**
- عقد: `AS7265X Sensor` → `ESP32 MCU` → `BLE Link` → `Flutter App` → `ML Model (TFLite)` → `SQLite Storage` → `Result UI`
- كل عقدة عند النقر: اسم المكون، دوره، لماذا هذا الاختيار.
- خطوط تحمل تسمية: `I²C`, `BLE 4.2`, `Local Inference`, `...`.

## 7. التنقل والأنماط التفاعلية (Navigation & Interactions) `[معتمد]`

### 7.1 Primary Navigation (Top Bar)

```
[شعار مصغَّر / الاسم]  [Methodology] [Expertise] [Projects] [Contact]  [EN/AR] [☾/☀] [CV ↓]
```

**السلوك:**
- ثابت sticky مع خلفية شبه شفافة + blur خفيف.
- يصغر ارتفاعه عند التمرير لأسفل.
- Mobile: الروابط تنطوي خلف Hamburger، لكن أزرار اللغة والـ Theme تبقى ظاهرة.
- لا يختفي عند التمرير لأسفل.

### 7.2 Language Switch UX

- زر واحد يعرض اللغة البديلة.
- عند التبديل: `document.documentElement.lang` و `dir` يتغيران فورياً، + حفظ في LocalStorage.
- الأولوية: `LocalStorage` > `Accept-Language header` > العربية كافتراضي.
- **ممنوع إعادة تحميل الصفحة عند التبديل.**

### 7.3 Theme Switch UX

- ثلاث حالات: `Auto` / `Dark` / `Light`.
- أيقونة قمر/شمس/نقطة.
- الأولوية: `LocalStorage` > `prefers-color-scheme` > Dark كافتراضي.
- Transition 200ms على المتغيرات اللونية.

### 7.4 أنماط Micro-interactions المعتمدة

| العنصر | السلوك |
|---------|---------|
| الأزرار الأساسية | Hover: توهج خفيف للـ border، لا تكبير |
| بطاقات المشاريع | Hover: رفع خفيف (2-3px) + تغيير لون الإطار |
| العقد في المخطط التفاعلي | Hover: توهج + تمييز الروابط المتصلة |
| روابط التنقل | Underline يتوسع من اليسار (أو اليمين في RTL) |
| نموذج التواصل | Validation فورية، رسائل خطأ تحت الحقل |
| CTA الرئيسي | Hover: انقلاب خفيف للألوان |

**القاعدة الحاكمة:** كل تفاعل يأخذ أقل من 300ms وقابل للتعطيل عبر `prefers-reduced-motion`.

## 8. القرارات البصرية المفاهيمية (Visual Conceptual Decisions) `[معتمد كتوجه]`

### 8.1 نظام الألوان — Dark Mode (الوضع الأساسي)

| الدور | Token | التوجه اللوني |
|-------|-------|-----------------|
| Background Primary | `--bg-primary` | Dark Navy عميق جداً (#0A1628 نقطة انطلاق) |
| Background Secondary | `--bg-secondary` | Deep Charcoal (#0F1419) |
| Surface | `--surface` | Midnight Blue (#152235) |
| Surface Elevated | `--surface-elevated` | #1C2B45 |
| Border Subtle | `--border` | رمادي أزرق بتعتيم خفيف |
| Primary Accent | `--accent-primary` | Electric Blue (#38BDF8 أو #22D3EE) |
| Secondary Accent | `--accent-secondary` | Cyan (#67E8F9) |
| Text Primary | `--text-primary` | #F1F5F9 |
| Text Secondary | `--text-secondary` | #94A3B8 |
| Text Muted | `--text-muted` | #64748B |

**حالات التصنيف:**
- Success: أخضر مكتوم (#10B981).
- Warning: عنبري مكتوم (#F59E0B) — للمشروع قيد التصميم.
- Info: الـ Primary Accent.
- Error: أحمر مكتوم (#EF4444) — للنماذج فقط.

**القاعدة:** ألوان التصنيف تُستخدم في الشارات فقط، لا كخلفيات لأقسام كاملة.

### 8.2 نظام الألوان — Light Mode (الوضع الثانوي)

- Background Primary: #FAFBFC.
- Background Secondary: #F1F5F9.
- Primary Accent: Blue أعمق (#0284C7) لضمان التباين.
- Text Primary: #0F172A.

**مبدأ إلزامي:** WCAG AA (4.5:1 للنصوص العادية، 3:1 للنصوص الكبيرة).

### 8.3 نظام الطباعة — التوجه

| العنصر | التوجه |
|---------|---------|
| الخط العربي | `IBM Plex Sans Arabic` أو `Tajawal` أو `Readex Pro` |
| الخط الإنجليزي | `Inter` أو `Space Grotesk` |
| خط الأكواد | `JetBrains Mono` أو `Fira Code` |
| مقياس الحجم | Modular Scale 1.25 (Major Third) |
| Line Height | 1.6 للنصوص، 1.3 للعناوين |

**قاعدة:** تُحمَّل من Google Fonts أو تُستضاف محلياً، مع `font-display: swap`.

### 8.4 نظام المسافات (Spacing System)
