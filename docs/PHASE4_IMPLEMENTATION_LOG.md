### ملاحظات

- **Auto مقابل "Dark افتراضي":** المتصفحات الحديثة تُبلغ `light` عندما لا يحدد المستخدم تفضيلاً. لذلك سيرى معظم زوار الأنظمة بالإعداد الافتراضي الوضع الفاتح، و Dark يبقى fallback فقط. هذا مطابق لترتيب الأولوية الموثق (`PHASE2_IA` § 7.3).
- **CSP:** سكربت Bootstrap مضمَّن (inline)، فيجب إضافة hash له في `script-src` عند تفعيل CSP لاحقاً.

## الخطوة 3 — BaseLayout + Header + Footer + i18n core + الخطوط

- **التاريخ:** 16 نوفمبر 2026
- **Commit:** `e1a866d` — `feat: add base layout, header, footer, i18n core and self-hosted fonts`
- **الحالة:** منفذة — بانتظار الاعتماد.

### ما تم

- **الخطوط (معتمدة من صاحب المشروع):** IBM Plex Sans Arabic (400/500/700، مجموعة الحروف العربية فقط)، Inter (Variable، Latin)، JetBrains Mono (Variable، Latin). كلها في `public/fonts/` مع `font-display: swap` وملفات ترخيص OFL. الحجم الكلي ≈ 221KB؛ يُحمَّل مسبقاً (preload) ملفان فقط: Plex 400 و Inter.
- **i18n core:** `src/locales/{ar,en}.json` (Dot notation، تنظيم Section → Key)، `src/lib/i18n.ts` (`t()`، `translations()`، `i18nAttrs()`، ومفاتيح مُتحقَّق منها في TypeScript)، و `src/lib/i18n-config.ts` (ثوابت خفيفة للعميل).
- **المكوّن `T.astro`:** يعرض النص باللغتين، و CSS يُظهر اللغة النشطة فقط.
- **`src/scripts/language-toggle.ts`:** `applyLocale` / `setLocale` تبدّل `lang` و `dir` وعنوان الصفحة والسمات المترجمة دون إعادة تحميل. زر التبديل نفسه في الخطوة 4.
- **BaseLayout:** سكربت Bootstrap واحد (الوضع + اللغة) قبل أول رسم، Preload للخطوط، رابط "انتقل إلى المحتوى"، و `<main id="main">`.
- **Header:** ثابت (sticky)، خلفية شبه شفافة مع blur، يصغر من 72 إلى 56px عند التمرير، روابط المحطات الأربع، زر CV، وقائمة Hamburger للجوال (Esc للإغلاق، `aria-expanded`، وتسمية مترجمة).
- **Footer:** حقوق النشر باسم صاحب المشروع + رابط Privacy Policy.
- **الصفحة الرئيسية:** هيكل المحطات السبع بمعرفاتها (`#hero` … `#contact`) وعناوينها فقط — لا محتوى مُختلق.
- **تحقق في Chromium:** عربي/إنجليزي × داكن/فاتح × Desktop/Mobile. الاتجاه والخطوط والسمات المترجمة والقائمة والتصغير تعمل، بلا تمرير أفقي وبلا أخطاء في Console.

### قرارات مستقلة

## الخطوة 16 — GitHub Actions (النشر) + CSP

- **التاريخ:** 17 نوفمبر 2026
- **Commit:** `e3d4afe` — `ci: add GitHub Pages deploy workflow and production CSP`
- **الحالة:** منفذة ومختبرة — **الإطلاق الفعلي بانتظار اعتماد صاحب المشروع** (الدمج في `main`).

### ما تم

- **`.github/workflows/deploy.yml`** (`PHASE3_ARCH` § 7.1) مع إضافات:
  - **على Pull Request إلى `main`:** فحص فقط (lint + format + type check + build)، بلا نشر. فحص قبل الدمج يمنع نشر نسخة معطوبة.
  - **على الدفع إلى `main` (أو يدوياً):** build ثم deploy إلى GitHub Pages.
  - صلاحيات دنيا: `contents: read` عامة، و `pages: write` + `id-token: write` لوظيفة النشر فقط.
  - Node من `.nvmrc` (20) مع cache لـ npm.
  - المتغيرات العامة الاختيارية: `PUBLIC_CONTACT_FUNCTION_URL`، `PUBLIC_UMAMI_URL`، `PUBLIC_UMAMI_SITE_ID`. غيابها يعطل الميزة المرتبطة دون إفشال البناء.
- **CSP كوسم meta في الإنتاج فقط** (`PHASE3_ARCH` § 10.2):
  `default-src 'self'; script-src 'self' 'sha256-…'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; font-src 'self'; connect-src 'self' <أصل دالة التواصل>; object-src 'none'; base-uri 'self'; form-action 'self'`
  - hash سكربت Bootstrap يُحسب تلقائياً وقت البناء، فلا يتعطل عند تعديل السكربت.
  - أصل `connect-src` يُستخرج من `PUBLIC_CONTACT_FUNCTION_URL`.
- **`docs/DEPLOY_CHECKLIST.md`:** قائمة الإطلاق (`engineering:deploy-checklist`): قبل الدمج، الإطلاق، التحقق، والتراجع.

### التحقق

- YAML الـ Workflow صالح (وظيفتان: build، deploy).
- **CSP:** بناء إنتاجي مع رابط دالة تجريبي:
  - **5 صفحات بلا أي مخالفة CSP**؛ السكربت المضمَّن يعمل (الوضع يُطبَّق)، والخطوط والصور تُحمَّل، والأزرار والمخطط يعملان.
  - **طلب النموذج إلى أصل الدالة مسموح** (وصل الطلب؛ فشل الشبكة متوقع لرابط تجريبي، وظهرت رسالة الفشل الصحيحة).
  - **اختبار سلبي:** سكربت مضمَّن محقون **لم يُنفَّذ**، وطلب `fetch` إلى نطاق خارجي **حُجب**.

| القرار | المبرر |
